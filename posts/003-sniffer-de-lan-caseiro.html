sniffer de lan caseiro

2026-10-10 · #rede #python #lab
aviso: só na tua própria rede, nos teus próprios dispositivos. Capturar tráfego alheio sem autorização é crime.

Queria saber quem, dentro da minha rede, anda a falar com quem (e porquê é que a televisão fala tanto). Resultado: um sniffer que lê cabeçalhos IPv4 e conta os destinos mais frequentes.

o código

#!/usr/bin/env python3
# precisa de root. so linux. so cabecalhos, nada de payload.
import socket, struct
from collections import Counter

s = socket.socket(socket.AF_PACKET, socket.SOCK_RAW, socket.ntohs(0x0003))
destinos = Counter()

try:
    while True:
        raw, _ = s.recvfrom(65535)
        eth_proto = struct.unpack("!H", raw[12:14])[0]
        if eth_proto != 0x0800:          # so IPv4
            continue
        ip = raw[14:34]
        _, _, _, _, _, _, proto, _, src, dst = struct.unpack("!BBHHHBBH4s4s", ip)
        src, dst = socket.inet_ntoa(src), socket.inet_ntoa(dst)
        destinos[dst] += 1
        print(f"{src:>15} -> {dst:<15} proto={proto}")
except KeyboardInterrupt:
    print("\ntop destinos:")
    for ip, n in destinos.most_common(10):
        print(f"{n:6}  {ip}")
