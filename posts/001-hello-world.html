Este site é um caderno. Cada entrada é um projeto pessoal: uma ideia, a tentativa de a fazer funcionar, e o que sobrou depois do café.

porquê assim

Porque a web original era isto: um ficheiro de texto, um link, e um browser que não pedia licença para existir. Hoje um blog precisa de bundler, runtime, três serviços na cloud e um banner de cookies. Aqui precisas de um editor de texto.

como está montado

beta_site_me/
├── index.html        # a página principal
├── css/style.css     # todo o visual
├── js/main.js        # terminal, filtros
├── js/posts.js       # índice de posts (editas aqui)
└── posts/            # um .html por post

Para ver: abre index.html no browser. Para servir a sério: 

python3 -m http.server 8000

o que esperar

  • projetos, completos ou abandonados a meio
  • código que podes copiar sem pedir licença
  • zero analytics, zero trackers
view source é uma funcionalidade, não um bug.
